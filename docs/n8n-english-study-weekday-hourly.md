# n8n Daily English Study Sender

현재 영어 학습 워크플로는 여러 영어 뉴스 RSS에서 최신 항목을 가져와, 매 실행마다 다른 `5개` 묶음을 골라 텔레그램으로 보냅니다.

## 현재 구성

- 워크플로 ID: `ubG6kTpNojt5rvZQ`
- 워크플로 URL: `http://127.0.0.1:5678/workflow/ubG6kTpNojt5rvZQ`
- 실행 시각: 매일 `12:00`, `19:00`
- 전송 방식: `HTTP Request` 노드로 Telegram Bot API 직접 호출

## 메시지 형태

매 실행마다 아래 구조로 한 메시지를 보냅니다.

- 학습 원문 `5개`
- 각 기사마다 구분선 추가
- 제목, 제목 해석, 원문, 본문 해석을 라벨과 함께 출력
- 기사마다 주요 단어 `3개`
- 각 단어마다 `뜻: 한글 뜻1, 한글 뜻2 (품사)` 형태로 출력
- 가능한 경우 활용형은 원형으로 표시하고, 원형 기준으로 뜻과 품사를 정리
- `Hungary's` 같은 소유격은 후보 선정 전에 소유격을 제거해 고유명사 필터가 적용되도록 처리
- 고유명사, 약어, 내부 대문자가 섞인 브랜드/인명형 토큰은 기본적으로 제외하고, 명사/동사/형용사/부사 중심으로 추출
- 같은 실행 메시지 안에서는 가능한 한 같은 원형 단어가 반복되지 않게 조정
- 뜻 목록은 사전 API 품사를 우선하고, 품사가 맞는 한글 뜻을 최대 `3개`까지 정리
- 가능한 경우 `유의어:`를 함께 출력

포함하지 않는 항목:

- 발행일
- 출처 링크
- 추천 학습 방법
- 추가로 볼 항목

## 동작 흐름

1. `Schedule Trigger`가 정해진 시각에 실행됩니다.
2. `외부 영어 자료 가져오기` 노드가 `Breaking News English RSS`를 읽습니다.
3. `원문 5개 선택` 노드가 RSS 전체 항목 중 실행 시점 기준으로 회전 선택한 원문 5개와 주요 단어를 정리합니다.
4. `단어 조회 펼치기`, `단어 뜻 조회`, `단어 사전 조회` 노드가 원형 기준으로 뜻을 조회하고, 사전 품사를 우선해 한글 뜻과 유의어를 정리합니다.
5. `메시지 조립` 노드가 가독성 높은 학습 메시지 형태로 합칩니다.
6. `텔레그램 전송` 노드가 채팅 ID(워크플로의 `YOUR_TELEGRAM_CHAT_ID`를 본인 값으로 바꿔 import)로 보냅니다.
