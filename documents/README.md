# 문서 보관 규칙

- 보고서·조사 결과: `reports/YYYY-MM/YYYY-MM-DD-주제.md`
- 일반 문서·가이드: `notes/YYYY-MM/YYYY-MM-DD-주제.md`
- 날짜는 실제 작성일을 사용합니다. 새 문서는 같은 이름의 기존 파일을 덮어쓰지 않습니다.
- 사용자가 별도 경로나 형식을 지정하면 그 요청을 우선합니다.
- 완료 응답에는 작업공간 기준의 정확한 파일 경로를 포함합니다.
- 대시보드 AI 실험실의 문서함에서 열거나 다운로드할 수 있습니다.
- 기존 `out/research/` 문서도 문서함에 표시합니다.
